# 小人乱斗

原创的横版一对一格斗游戏原型。战斗规则是真实可玩的，角色、场景和音效全部由代码生成，没有任何外部素材。提供电脑对战与训练模式，单机运行，不需要联网。

- 在浏览器里直接玩：https://xingxuan-platform.pages.dev/tools/xiaoren-luandou/
- Windows 版下载：见本仓库的 [Releases](https://github.com/chenyihang98-pixel/xiaoren-luandou/releases)

## Windows 版怎么用

1. 下载 zip，用 Windows 的「全部解压缩」解压到一个新文件夹，不要「解压到当前文件夹」。
2. 双击里面的 `ArcadeFighter.exe`。整个文件夹就是这个游戏，不能只把 exe 单独拷走。
3. 不需要安装，不需要联网，关闭窗口即退出。
4. 程序没有数字签名，首次运行时 Windows SmartScreen 可能提示，点「更多信息 → 仍要运行」即可。请不要为此关闭系统安全设置。

Windows 10 / 11，64 位。

## 操作

| 操作 | 默认按键 |
|---|---|
| 移动 | A D 或 ← → |
| 跳跃 / 下蹲 | W S 或 ↑ ↓ |
| 轻攻击 | J 或 Z |
| 重攻击 | K 或 X |
| 特殊技（脉冲弹） | L 或 C |
| 防御 | 按住远离对手的方向 |
| 确定 / 返回 | Enter、Space / Esc |
| 暂停 | Esc 或 P |

七个战斗操作的主键都可以在游戏里「设置 → 键盘」修改。

## 说明

- 这是原型版本。画面与音效是用代码生成的临时方案，不是最终美术方向。
- 目前只有一名角色 NOVA，电脑对手是同一角色的第二套配色。
- 游戏内暂时仍显示工程期的名称「街机格斗」。
